# Smart Lishe AI

Smart Lishe AI is an intelligent nutrition assistant that uses Retrieval-Augmented Generation (RAG) to answer food and nutrition questions.

## Features

- Nutrition knowledge base
- Semantic search using embeddings
- Qdrant vector database
- AI-generated responses
- Food image recognition (planned)
- Meal recommendations (planned)

## Technologies

- Python
- Sentence Transformers
- Hugging Face
- Qdrant
- GPT-Neo
- Pandas

## Project Structure

- data_prep.py
- embeddings.py
- qdrant_store.py
- rag_agent.py
- llm_integration.py
